# ADR-007: Minimal Preset — Narrow Braille Gauge Strip for pi-sidebar
- **Date:** 2026-09-03 08:53:53
- **Status:** active
- **Context:** Sidebar telemetry duplicated eldritch-footer statusline content (context bar, cost, cache, quotas). User wanted a mode that almost hides the sidebar (~40px) while keeping at-a-glance indicators: circular context usage chart with percentage, etc.
- **Decision:** Added new `minimal` preset rendered as a narrow strip (8–12 columns, default 10 on switch): braille ring gauge (new `src/gauge.ts`, U+2800 dot grid, plain Euclidean distance since braille dots are screen-square) filling clockwise from 12 o'clock with colored percent line and cost; thinking-level emoji; worst-of-windows quota mini-bar (contextBar, 70/90% color thresholds); git dirty/clean dot with ahead/behind arrows; MCP/LSP readiness dots. Minimal mode suppresses the bottom Git dock, ZKRATKY hints, and branding sections. Width bounds lowered 16→8 (config.ts, index.ts, commands.ts); preset switch to minimal auto-shrinks width to 10, switching back restores 28. Complements footer: footer keeps full text telemetry, sidebar shows gauges only.
- **Consequences:** Ring pct text sits below ring (too small to embed inside 5-char ring). Braille ring is decorative-only resolution (10x12 dots). resolveNumber width min now 8 for all presets — user could set odd widths on wide presets. 4 files + gauge.ts + tests (14 pass); duplication with eldritch-footer resolved by preset pairing: /sidebar preset minimal + /footer detailed.
